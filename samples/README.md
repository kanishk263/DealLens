# Synthetic sample documents

**All companies and figures in this folder are fictional** and exist only to demonstrate and test DealLens.
Regenerate with `npm run samples` (script: `scripts/generate_synthetic_data.py`). `manifest.json` contains the
generating model's values, which the automated tests use as known answers.

| File | Company | Purpose |
|---|---|---|
| `northstar-financial-statements.xlsx` | Northstar Components (manufacturing, moderate growth, stable margins) | Clean three-statement workbook |
| `northstar-income-statement.pdf` | Northstar | Text-based PDF extraction (page references) |
| `meridian-financial-statements.xlsx` | Meridian Consumer Brands (rising revenue, deteriorating working capital) | Red flags and a reconciliation variance |
| `apex-financial-statements.csv` | Apex Digital Services (high gross margin, asset-light) | Stacked statements in one CSV (row/column references) |
| `apex-revenue-by-customer.xlsx` | Apex | Customer schedule (concentration analysis after analyst confirmation) |
| `scanned-statement-unsupported.pdf` | — | Image-only PDF used to verify the "OCR not supported" path |

## Deliberate inconsistencies

The statements are generated by a three-statement model (the balance sheet balances and the cash roll-forward
reconciles) **except** for these intentional issues:

- **Northstar**: expenses are shown as negative numbers in parentheses (sign-convention handling); a "Gross margin %"
  ratio row is present and ignored by extraction.
- **Meridian**: FY2024 *Total assets* is overstated by **150** versus its components (balance-sheet variance);
  the income statement includes an unmapped label *"Brand royalty pool"*; the profile is designed to trigger
  gross/EBITDA-margin deterioration, receivables- and inventory-outpacing-revenue, OCF below EBITDA, negative FCF and
  working-capital absorption red flags.
- **Apex**: *reported* EBITDA excludes share-based compensation (800 / 950 / 1,100), so it differs from EBIT + D&A;
  no inventory (service business) so DIO is unavailable; customer A is 28% of revenue.
